Descripción del proyecto

Este proyecto es una solución de automatización de procesos de análisis de datos orientada a la gestión de bonos de empleados.
Permite procesar información de ventas, calcular bonos, detectar anomalías mediante técnicas de análisis de datos y generar reportes automatizados en Excel y base de datos.
El sistema integra Python, Pandas, SQL y lógica de negocio, simulando un flujo real de trabajo en un entorno corporativo.

Objetivo
Automatizar el cálculo de bonos de empleados en base a su rendimiento, garantizando:

Limpieza y transformación de datos
Cálculo automático de cumplimiento de metas
Generación de bonos por rendimiento
Detección de anomalías en los datos
Exportación de resultados a Excel y base de datos SQL
